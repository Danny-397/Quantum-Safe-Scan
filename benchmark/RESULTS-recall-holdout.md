## Every miss

- `paramiko/paramiko-5.1.0/tests/test_transport.py` lines 1228 (ecc): Asserts the advertised server-sig-algs list, which includes ssh-ed25519 and ecdsa-sha2-nistp*
- `requests-oauthlib/requests-oauthlib-2.0.0/tests/test_oauth1_session.py` lines 7, 116, 279, 303, 304 (rsa): Imports SIGNATURE_RSA and signs OAuth1 requests with RSA-SHA1 using a test RSA key (the expected-header strings are excluded)
- `scrapy/scrapy-2.19.0/scrapy/pipelines/images.py` lines 21, 157 (md5): Imports the _md5sum helper and checksums each image with it

Labels were written after the scanner fixes prompted by the first sample, and before the scanner was run on any held-out file: each file was read in full, or for long files every line a broad search for algorithm names surfaced plus its surrounding code. Same counting rule as the first sample: a usage counts when executable code uses, configures, selects, imports or implements the algorithm; names in comments, docstrings, messages and test names, and flags or lists that turn an algorithm off, do not.
