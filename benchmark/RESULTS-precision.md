## Definition used

A finding is a true positive when the flagged line uses, configures or implements the named algorithm in executable code: a call, an import of it, an identifier or constant that selects it, or a table entry the code acts on. It is a false positive when the name appears only in inert text (comment, docstring, message), when an identifier merely resembles the name, when the line's algorithm is not the one reported, or when the line turns the algorithm off (a finding implies exposure). Labels were assigned by reading each finding's source context; this measures precision only, not recall, which the seeded benchmark covers.
